# Security Policy

## Supported Versions

| Version | Supported | Maintenance Level |
|---|---|---|
| 1.0.x (main branch) | Yes | Active security patches and data fixes |
| < 1.0.0 | No | End of Life |

---

## Reporting a Vulnerability

If you identify a security issue, sensitive data leak, or dataset integrity vulnerability:
- Email maintainer: `izuki99999@gmail.com` with subject `[SECURITY] UNS Prodi Directory Report`.
- Include clear reproduction steps, potential impact assessment, and affected components.
- Please do not open public GitHub issues for security vulnerabilities before they are reviewed.
- Initial triage and acknowledgment will be provided within 48 hours.
