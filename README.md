## Bahasa Indonesia

Pusat basis data terbuka dan direktori web interaktif untuk seluruh program studi, peringkat akreditasi nasional dan internasional, rumpun ilmu, lokasi kampus, daya tampung, serta fakultas di **Universitas Sebelas Maret (UNS)**, Surakarta.

Dibuat untuk calon mahasiswa (persiapan seleksi SNBP, SNBT, dan Seleksi Mandiri), mahasiswa aktif, akademisi, serta pengembang perangkat lunak yang membutuhkan dataset pendidikan tinggi terstruktur.

### Fitur Utama

- **Pencarian Real-Time:** Cari prodi berdasarkan nama, kode prodi, maupun fakultas pengelola secara instan.
- **Antarmuka Dwibahasa:** Dukungan alih bahasa instan antara **Bahasa Indonesia** dan **English**.
- **Tinjauan Detail Komprehensif (Prodi Overall View):** Klik kartu atau baris tabel prodi untuk membuka jendela profil lengkap yang merinci deskripsi keilmuan, apa yang dipelajari (fokus kurikulum inti), serta prospek karir lulusan.
- **Filter Multi-Kategori Komprehensif:**
  - Jenjang Pendidikan: Sarjana (S1), Sekolah Vokasi (D3/D4), dan Pascasarjana (S2/S3).
  - Fakultas & Sekolah Pengelola: FATISDA, FT, FK, FEB, FH, FKIP, FISIP, FIB, FP, FPET, FSRD, FKOR, FPSI, FMIPA, SV, SPS.
  - Rumpun Ilmu: Sains & Teknologi (Saintek), Sosial Humaniora (Soshum), Keolahragaan, dan Multidisiplin.
  - Lokasi Kampus: Kampus Utama Kentingan Surakarta, PSDKU Kebumen, dan PSDKU Madiun.
  - Peringkat Akreditasi: Unggul, Baik Sekali, Baik, Nilai A, dan Nilai B.
- **Akreditasi Internasional:** Penanda khusus untuk prodi yang telah tersertifikasi oleh lembaga internasional seperti **ASIIN**, **AQAS**, **FIBAA**, dan **IABEE**.
- **Deep Linking:** Pencarian, filter aktif, serta jendela profil prodi terbuka (`?prodi={id}`) otomatis tersinkronisasi ke parameter URL peramban untuk memudahkan berbagi tautan langsung.
- **Salin Tautan:** Tombol salin tautan langsung untuk membagikan kartu dan profil informasi prodi spesifik.
- **Tampilan Fleksibel:** Beralih dengan mudah antara visual kisi kartu (grid view) dan tabel data ringkas (table view).
- **Peringatan Kesegaran Data:** Notifikasi otomatis jika data belum diperbarui dalam 90 hari terakhir.
- **Zero-Dependency Deployment:** Siap dijalankan langsung melalui **GitHub Pages** tanpa proses kompilasi atau dependensi npm.

## English

An open data repository and interactive web directory for all study programs, accreditation ratings (National and International), academic disciplines, campus locations, admission quotas, and faculties at **Universitas Sebelas Maret (UNS)**, Surakarta, Indonesia.

Designed for prospective university applicants (preparing for SNBP, SNBT, and Seleksi Mandiri admissions), current students, researchers, and developers seeking structured higher education open datasets.

### Key Features

- **Real-Time Search:** Search study programs instantly by program name, program code, or managing faculty.
- **Bilingual Interface:** Instant language switching between **Bahasa Indonesia** and **English**.
- **Interactive Study Program Overview:** Click any study program card or table row to open a comprehensive detail modal (academic discipline overview, core curriculum/what it teaches, and career opportunities).
- **Comprehensive Multi-Level Filters:**
  - Degree Levels: Undergraduate (S1), Vocational School (D3/D4), and Postgraduate (S2/S3).
  - Managing Faculties & Schools: FATISDA, FT, FK, FEB, FH, FKIP, FISIP, FIB, FP, FPET, FSRD, FKOR, FPSI, FMIPA, SV, SPS.
  - Academic Disciplines: Science & Technology (Saintek), Social Sciences & Humanities (Soshum), Sports, and Multidisciplinary.
  - Campus Locations: Surakarta Main Campus (Kentingan), PSDKU Kebumen, and PSDKU Madiun.
  - Accreditation Rankings: Superior (Unggul), Very Good (Baik Sekali), Good (Baik), Grade A, and Grade B.
- **International Accreditation Badges:** Highlights programs certified by international accreditation bodies including **ASIIN**, **AQAS**, **FIBAA**, and **IABEE**.
- **Deep Linking:** Search queries, active filter states, and open program modal views (`?prodi={id}`) synchronize with the browser URL for seamless link sharing.
- **Permalinks:** Direct copy button to share specific study program cards and detail views.
- **Flexible Layouts:** Toggle seamlessly between an informative grid card view and a compact data table.
- **Automated Freshness Warning:** Alerts visitors automatically if data has not been updated within 90 days.
- **Zero-Dependency Deployment:** Ready to deploy immediately to **GitHub Pages** or **Vercel** with no compilation steps or npm packages required.
